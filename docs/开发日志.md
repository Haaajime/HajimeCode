## 2026-09-28 · W1：主图骨架与预算链路

- **内容**：搭建工程骨架并实现 LangGraph **双层图**最小闭环，端到端可跑、全离线可测。
  - 主图（手写 `StateGraph`）：`intake → plan → act → reflect ─┬→ act（未过验收，带意见重试）/ └→ finalize`。
  - `act` 节点内部为官方 `create_agent` 装配的 ReAct 子图。
  - 预算链路：`UsageTracker`（callback handler）累计 token / **缓存命中** / 成本，经 `add_budget` reducer 汇总。
  - 文件工具：`read` / `list_dir` / `glob` / `write` / `edit`，全部经 `Workspace` 做路径边界校验。
- **技术核对（发现并修正两处认知）**：
  - `langchain.agents.middleware` **已内置** `TodoListMiddleware` / `SummarizationMiddleware` / `HumanInTheLoopMiddleware` / `ShellToolMiddleware`（含 Docker 执行策略）/ `ModelCallLimitMiddleware` 等 → W5 策略改为「复用官方 + 只自研官方没有的」，自研重心转向混合检索、成本缓存核算、权限策略、图控制流。
  - `create_agent` 签名为 `system_prompt` / `middleware` / `checkpointer`；`ChatOpenAI` 的 token 上限参数是 `max_completion_tokens`（非 `max_tokens`）。
