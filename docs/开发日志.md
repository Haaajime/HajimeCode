## 2026-09-28 · W2：后端 API + SSE 事件流 + 前端控制台

- **内容**：把图执行服务化，并交付可实时观察 Agent 每一步的 Web 控制台。前端由终端形态升级为产品形态。
  - **事件翻译层**（`serve/events.py`）：把 LangGraph 三种 stream 模式翻译成统一事件协议，纯函数、可单测。
  - **事件总线**（`serve/bus.py`）：线程安全发布（图在 worker 线程跑，订阅者在事件循环读），支持历史回放与 `Last-Event-ID` 续传。
  - **执行器**（`serve/runner.py`）：消费图 stream、累计预算、发布事件、收束最终状态。
  - **FastAPI**（`serve/app.py`）：`POST /api/tasks` 立即返回（长任务不阻塞 HTTP）、`GET /api/tasks/{id}/events` SSE 推流、静态托管前端。
  - **前端**（`web/`）：Vite + React 19 + TS + Tailwind v4；提交任务、实时时间线（节点 / 工具调用 / 模型 token 流）、成本与缓存命中条。
- **技术核对（实测而非照抄文档）**：
  - `subgraphs=True` 时流条目是 **3 元组** `(namespace, mode, data)`；不传则 2 元组。
  - `debug` 模式给出 `task` / `task_result`，正好对应 `node.started` / `node.finished`。
  - `messages` 模式的 metadata 含 `langgraph_node`，可归属节点。
  - **踩坑**：`messages` 模式会把节点写入的**普通消息**也流出来（如 `intake` 写入的 `HumanMessage`），最初把用户输入误报成 `llm.token`。已加 `isinstance(chunk, AIMessageChunk)` 过滤并补单测。
  - **可离线验证 token 流**：用官方 `GenericFakeChatModel` + 真实 `create_agent`，不碰网络即可复现真实流形状。
- **偏离方案一处**：SSE 改用**原生 `EventSource`**，不用 `@microsoft/fetch-event-source`。理由：本项目流式端点是 GET，不需要自定义 header（`Last-Event-ID` 由浏览器在重连时自动带上），少一个依赖。该库只在需要 POST 建流时才有必要。
- **改动文件**：
  - `src/hajime2code/serve/`：`events.py` `bus.py` `store.py` `runner.py` `app.py` `__main__.py` `__init__.py`
  - `web/`：`package.json` `vite.config.ts` `tsconfig.json` `index.html`、`src/{main.tsx,App.tsx,api.ts,index.css}`、`src/components/{TaskForm,TaskList,Timeline,CostBar}.tsx`
  - `tests/`：`test_serve_events.py` `test_serve_bus.py` `test_serve_runner.py` `test_serve_api.py`
  - `README.md`（Web 快速开始）、`.github/workflows/ci.yml`（新增 web 构建 job）、`.gitignore`、`pyproject.toml`（新增 `hajime2code-web` 脚本）
- **测试结果**：`ruff check` 通过 · `ruff format --check` 通过 · `mypy`（27 文件）0 错误 · `pytest` → **64 passed**。
  其中 `test_serve_runner.py::test_end_to_end_with_real_agent_and_fake_model` 用真实 `create_agent` + 官方假模型跑通全链路（含 token 流），**零网络**。
- **前端构建**：`tsc --noEmit` 0 错误 · `vite build` 成功（dist 74 KB gzip）。
