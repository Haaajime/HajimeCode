# 模块开发进度与优先级（Agent Harness / HajimeCode）

> 本文档是**模块级开发的权威记录与排队依据**。以"完成一项 → 记日志 → git commit"为准,

## 优先级说明

- **P0**：立即推进（当前手头/Coding 场景底座，影响后续模块）
- **P1**：近期（简历核心卖点、框架完备性关键项）
- **P2**：之后/按需（增强项，可在主体稳定后再做）
