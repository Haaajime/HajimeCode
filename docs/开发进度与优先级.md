## 路线总览（10 周）

前端提前到 W2 起随能力渐进生长，避免"最后一次性做前端"导致反复重写。

| 周 | 主题 | 状态 |
|---|---|---|
| W1 | 立项与骨架（双层图 + 预算链路 + 工具 + CI） | ✅ 已完成 |
| W2 | 后端 API + SSE 事件流 + 前端控制台 | ✅ 已完成 |
| W3 | Docker 沙箱 bash + 写工具人工审批（interrupt → 前端审批卡片） | ⬜ 下一步 |
| W4 | 持久化（PostgresSaver）+ time-travel（→ 前端「从这一步重跑」） | ⬜ |
| W5 | 机制层：复用官方中间件 + 自研成本/缓存核算（→ 前端成本条） | ⬜ |
| W6 | 混合检索（AST + 向量 + BM25 + RRF + rerank）+ 长期记忆 | ⬜ |
| W7 | 多 Agent 拓扑（single / supervisor / swarm / 自研子图） | ⬜ |
| W8 | 评测框架：F2P/P2P 任务集 + 指标 + 报告页 | ⬜ |
| W9 | E1 机制消融 · E2 拓扑对照 · E3 范式对照 · E4 压缩↔缓存对抗 | ⬜ |
| W10 | 收口：README / 架构图 / 报告归档 / 简历与面试话术 | ⬜ |
